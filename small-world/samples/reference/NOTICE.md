# 参照音声

このディレクトリの音声は**出力には入らない**。声の特徴を測るためだけに置いてある。

## 児童合唱の録音（本物）

`shine_on_me.ogg` / `summer.ogg` / `cantate.ogg`

- 出典: Wikimedia Commons
- 権利者/アップロード: **Childrenschorussa**（合唱団自身のアカウント）
- ライセンス: **CC BY-SA 3.0** ―― 権利者本人が付けた正当な自由ライセンス
- 各およそ29秒 / 44.1 kHz

**なぜこれを選んだか。** 「無料」と表示されている音源の大半は、
アップロード者が勝手に付けた表示で法的な裏付けが無い。archive.org で
"It's a Small World" を CC0 と宣言していた項目は、説明が "Disney World"
＝ ライドの録音を個人が CC0 と宣言したものだった。宣言する権利が無い。
Ivory Records 名義の子供向け歌集も同じ個人アカウントからの市販盤アップロード。
ここに置いたものだけが、**権利者本人が公開した**ものにあたる。

**測ってみた結果は使えなかった。** 声道長の比を求めようとしたが、ホールの
残響と遠いマイクで低域が乗っており、80〜500Hz のエネルギーが 52%（こちらの
歌声は 12%）。スペクトル重心の比は 0.68 ―― 「子供のほうが低い」と出る。
声道ではなく録音条件の差を測っている。周波数軸を伸ばしたときの相関も
0.63〜0.73 とほぼ平坦で、倍率が決まらない。多声の合唱を1人の声の参照に
するのも無理がある。

近接録音の**独唱**が1つあれば、この測定は成立する。

## 聴き比べ用

`voice_modes.wav`
: 同じ1行を Tiger の7声色すべてで。順に disco / electric / fresh / glam /
  mystic / royal / vinyl。0.7秒の無音で区切ってある。実測のスペクトル重心は
  779〜1101 Hz で、**どれも子供の声ではない**。

`child_formant.wav`
: 同じ1行のフォルマント倍率違い。順に 1.00 / 1.10 / 1.18 / 1.25 / 1.35。
  Tiger の `gender` 入力は負にすると出力が消えるので使えないが、こちらの
  WORLD で後段から動かすのは効く（`orchestra/audio/singer.py` の
  `warp_formants`）。歌としては既に出来上がっているものの共振だけを
  動かすので、喋りを歌に変換していたときのような無理は無い。
