# 退役したクリップ（物理楽器前提）

物理楽器を取り付ける設計だった頃のクリップ。エアー演奏への転換で使わなくなった。

置いてある理由は2つ。

1. **動きの形は今も参考になる。** 振りかぶり→打点→跳ね返り→復帰という構造は
   エアーでも同じで、新しいクリップはこれを土台にしている。
2. **なぜ落ちるかが記録として残る。** 打鍵の衝撃を前提にした速度免除
   （`impact_velocity_scale`）を廃止したので、この中の打鍵クリップは
   現在の検証を通らない（4.56〜4.67 rad/s vs 上限 4.0）。設計上そこで速度が
   跳ねるように作られていたため。

`ClipLibrary` は `clips/**/*.clip.json` を拾うので、拡張子を変えて無効化してある。
